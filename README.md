# Machine Learning Sentiment Classifier

A small Python project I built to explore the fundamentals of machine learning and natural language processing using scikit-learn.

## What It Does

The program trains a logistic regression model to classify short movie reviews as positive or negative.

It uses `CountVectorizer` to convert text into numerical features, then trains a `LogisticRegression` classifier on a small labeled dataset.

I also included output for the vocabulary, feature matrix, model coefficients, intercept, prediction probabilities, and final classification so I could examine how the model was making its decisions rather than treating it as a black box.

## Technologies

- Python
- scikit-learn
- CountVectorizer
- Logistic Regression
